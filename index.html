Firebase setup & security rules
  1. Open Firebase Console and create a project.
  2. Add a Web app and copy its apiKey, authDomain, projectId, and appId into the fields above.
  3. In Authentication → Sign-in method, enable Google.
  4. In Firestore Database, create a database.
  5. Publish these Firestore rules so each user can access only their own journal:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Firebase web config identifies your project; it is not a private server secret. Never publish service-account credentials. Add your deployed website domain under Firebase Authentication → Settings → Authorized domains.

Morningstar's trading rulebook

Keep the model fixed long enough to collect meaningful evidence. Change rules based on a sample, not one outcome.

01 · Direction

Establish the 30M directional bias using market structure.

02 · Location

Identify the relevant 5M/15M order block and fair value gap. The OB must precede displacement that breaks structure and leaves an FVG.

03 · Liquidity

Mark meaningful swing or session liquidity. Know what price needs to sweep before entry.

04 · Confirmation

Require the planned liquidity sweep and valid BOS. No confirmation, no entry.

05 · Entry

Wait for retracement into the planned FVG / POI. No retracement = no trade. Never chase a move that leaves without you.

06 · Risk

Define stop, position size, and target before entry. No full-margin trades, no widening the stop to avoid a loss.

07 · Discipline

No copying signals, revenge trades, or unplanned entries. A missed trade is not a reason to force another.

08 · Review

Record P&L, R multiple, rule compliance, emotion, mistake, and one lesson after every trade.

End-of-session questions

  • Did I follow my model, even if I lost?
  • Was my entry planned before price reached the POI?
  • Did fear make me exit early?
  • Did I take a trade because of someone else's analysis?
  • Did I respect my risk and trade limit?
  • What is the one behavior I will correct next session?

A rule-following loss can be a good trade. A profitable trade that breaks your rules can still be a bad trade.
